# 📊 BIH Data Analyst Journey

Welcome to my **Beacon Innovation Hub (BIH) Data Analyst journey**.

This repository documents my progression through the **BIH Data Analyst Pathway**, where I am developing the skills required to turn data into trustworthy evidence, meaningful insights, and decision-support information.

The journey is not about simply completing tutorials. It is about **learning by doing**.

## 🧠 My Learning Approach

```text
🎥 WATCH
   ↓
⏸️ PAUSE
   ↓
⌨️ RECREATE
   ↓
🔧 MODIFY
   ↓
🧩 SOLVE A BIH PROBLEM
   ↓
📚 CONSULT DOCUMENTATION
   ↓
🧠 UNDERSTAND
   ↓
🚀 BUILD
   ↓
📝 DOCUMENT
```

I want to understand **why** something works, not simply reproduce what someone else has done.

---

## 🎯 My Goal

My goal is to develop from a learner into a **job-ready Junior Data Analyst** who can independently:

* Define a business question
* Understand unfamiliar data
* Clean and validate data
* Analyse data
* Query relational databases using SQL
* Apply statistical reasoning
* Build meaningful KPIs
* Create business-intelligence dashboards
* Communicate findings clearly
* Make evidence-based recommendations
* Document analytical work professionally

The BIH pathway emphasises moving from foundational analysis toward relational data, statistical reasoning, business intelligence, and ultimately independent end-to-end analytical competence.
